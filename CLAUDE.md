# maths-lab

One Next.js site with nine maths projects. The user writes each project's maths cores; Claude Code builds everything else.

- Building or changing a project: read [BUILDERS.md](BUILDERS.md) first. Work only in `src/projects/<slug>/` and `src/app/<slug>/`.
- Never write the body of a maths core (`src/projects/<slug>/core/*.ts`). Stubs, specs and tests only.
- Black and white only, phone-first, static export.
